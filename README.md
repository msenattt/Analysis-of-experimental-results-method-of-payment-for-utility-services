# Анализ результатов A/B-теста: форма оплаты ЖКХ

## Вопрос

Влияет ли новая форма оплаты (группа B) на конверсию в успешный платёж по сравнению с текущей формой (группа A)? Стоит ли раскатывать новую форму?

## Короткий вывод

Конверсия в успешную оплату выросла с 65,8% до 80,4% — **+14,6 п.п.** (относительный прирост +22,2%). Эффект статистически значим: односторонний z-test, **p = 8,5×10⁻¹¹**, 95% доверительный интервал **[10,2; 19,0] п.п.** Максимальный прирост — на шаге «ввёл реквизиты → подтвердил» (+12,8 п.п., +17,5% относительно).

**Рекомендация:** раскатить новую форму и мониторить конверсию по когортам 2–3 месяца.

**Ограничение:** анализ покрывает один платёжный цикл — устойчивость эффекта для повторных платежей не проверена. Решение о полной раскатке принято с учётом этого окна.

## Данные

- **Источник:** учебный кейс по продуктовой аналитике (оплата услуг ЖКХ), тест новой формы с автозаполнением реквизитов, 1–30 апреля 2024.
- **Единица анализа:** пользователь. Платежи агрегируются до максимального достигнутого шага: пользователь считается дошедшим до шага, если дошёл хотя бы один его платёж.
- **Объём:** 1 503 пользователя (A = 752, B = 751), 2 660 платежей.
- **Очистка (выполнена до расчётов, зафиксирована в разделе 0 ноутбука):** исходные листы — 1 504 пользователя и 2 661 платёж; проверены SRM (сплит близок к 50/50), дубли и пересечения групп (не найдены), хронология шагов и границы периода (нарушений нет); пользователи с некорректным возрастом (< 18 или > 75 лет) переведены в пропуски (2 записи).
- **Окно наблюдения:** один платёжный цикл.

## Определения метрик

| Метрика | Определение |
|---|---|
| Конверсия на шаг | Доля пользователей группы, у которых хотя бы один платёж достиг шага |
| Конверсия в успешную оплату | Доля пользователей с платежом, дошедшим до step4_success |
| Время заполнения | step4_success − step1_opened в секундах (успешные платежи) |

## Ключевые проверки

- **Качество данных:** некорректный возраст (−5, 150) → пропуски; дубли и пересечение групп исключены на этапе подготовки (SRM-проверка).
- **Выбросы длительности:** метод межквартильного размаха (IQR); аномально долгие сессии (> 1200 сек., 9 платежей) учитываются отдельно при интерпретации.
- **Однородность групп:** возраст — t-тест (p = 0,83); город — хи-квадрат (p = 0,47); устройство — хи-квадрат (p = 0,053). Группы сопоставимы.
- **Значимость эффекта:** односторонний z-test пропорций «B > A», p = 8,5×10⁻¹¹; доверительные интервалы Уилсона для конверсий обеих групп не пересекаются.
- **Контроль побочных эффектов:** медианное время заполнения формы одинаково в обеих группах (720 сек.) — рост конверсии не достигнут ухудшением опыта.
